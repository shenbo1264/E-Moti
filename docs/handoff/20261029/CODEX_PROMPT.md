# 给 Codex：E-Moti 后端与宿主开发

你负责E-Moti后端、宿主服务与集成，Claude负责产品和前端。请基于真实最新仓库和交付包继续实现、测试和修正，不只给架构方案。先导入已有有效改动，避免重复重建已经解决的记忆问题。

## 产品与范围

E-Moti是独立人格、共同记忆的个人AI伙伴，可选工作/游戏/观察能力。关闭Relay或全部观察后仍可使用。角色应好奇、聪明、自然、有自己的风格与判断，偶尔吐槽，不过度讨好、催促或打扰；情绪不修改事实。

平台：保留Windows优先Python/PySide6，新增Android/HyperOS、iPhone/iOS、华为手机原生HarmonyOS。此前macOS是用户口误，不开发Mac桌面；鸿蒙限华为手机。手机聊天/任务共用宿主权威人格与记忆，平台观察能力独立协商。长程执行在电脑或可选常开宿主，不依赖手机无限后台保活。

只改E-Moti；Relay拥有真实任务/执行者/权限/验收状态，游戏Agent拥有游戏世界状态，Body项目负责固件。可只读核对真实外部接口，接口缺失写明对方需提供的能力，不擅自改造其他项目。

## 既有实现必须复用

- `app.py`实际使用`PluginEnabledCompanionController as CompanionController`。手机facade接这条已启用Emotional Memory V2、persona与失效传播的路径，不能只包基础controller。
- 复用`MemoryAlbumController`和现有记忆用例，保留来源/版本/时效/角色-owner-scope、事务纠正/遗忘、章节/画像失效、epoch、旧迁移防复活与语音取消。不能新建手机专用长期事实库绕过这些约束。
- `personal_tasks.py`已实现本地SQLite建议/批准/派发前记录/回执/取消/新鲜度；它不是runner/执行器/认证接口。
- `device_context.py`是默认关闭的RAM观察门控，ticket用于会话撤回，不是网络身份认证；完整派生历史/TTS/手机缓存撤回尚未接入。
- 已有Graphiti RRF实际复用与Apache许可保留。embedding、自动巩固/人格演进和真实模型holdout尚待开发；按效果证据决定，不先增加多套记忆数据库。

## 分工与首条切片

你主写controller、领域服务、存储/迁移、宿主facade、认证/传输、任务runner、Relay adapter及公共协议；Claude主写app.py/Qt widgets/展示view model和原生手机端。把宿主装配放独立模块，给Claude少量明确接入调用，避免共同覆盖app.py。公共依赖/构建/协议文件由一人主写，另一方评审。

先实现一条不依赖Relay的真实链路：已认证手机→正确线程/串行会话→当前角色回复→显式事实确认→跨端纠正/遗忘→旧来源/派生内容不能重入prompt→人格配置保持稳定。向Claude交付可运行的最小请求/响应/事件/错误契约，不凭空假定已存在HTTP路径。

采用适配当前Python工程的成熟网络和认证组件；不要手写密码协议。配对、撤销、凭据/权限和TLS在对外服务启用前完整考虑。请求正文自报owner/character/authority不可信，由认证映射；外部线程不能并发操作Qt或创建同一角色的多个写入权威。解决实际阻塞/取消问题，不先做泛化服务框架。

## 任务、长程与观察

紧接着核查Relay实际接口，完成能力发现、已批准提交、command ID核对、状态/事件、取消与结果引用。日志中的accepted不等于完成，外部报告完成不等于独立验收；丢回执先核对，避免盲重试。下游不支持查询/取消时如实呈现。

用现有task store增加必要的持续runner、检查/退避、预算/期限、阻塞处理、阶段报告和恢复。复用主动陪伴安静时段与节流，不另建催促引擎。经过批准范围内的正常推进无需反复询问。保留真实跨小时任务、重启、断网、电脑睡眠和取消证据。

观察输入与用户命令分开；工作/游戏/页面内容短期有效，不默认写长期画像。接入collector前让观察来源贯穿聊天、摘要、TTS和设备缓存；模型调用前与展示前检查版本，撤回/过期/重连/切角色时使派生信息同步失效。只清空buffer不能称为跨端遗忘。iOS26.4/27与华为手机的能力条件按新研究处理，不复制Android权限假设。
