# Claude / Codex 协作分工

日期：2026-10-29。用户指定 Claude 负责产品与前端，Codex 负责后端。两者都应实际实现职责内的工作，不以方案替代开发。完整范围见 [requirements.md](requirements.md)。

## 1. 一份集成基线，两个独立工作目录

先由 Codex 核对最新远端、分支、开放 PR 与本地未提交改动，把交付包纳入当前工程；已经存在的改动不要重复应用。确认一个共同 commit 后，Claude 与 Codex 从同一 commit 建独立分支/worktree。Claude 可同时开始只读需求整理和界面审阅，不需要等待后端写完才工作。

同一 Git 工作目录不能让两人轮流 `git switch`。也不要让两个 agent 直接覆盖同一套未提交文件。通常使用 `claude/product-ui` 与 `codex/host-backend` 等分支即可，无需另建协作平台。双方提供独立提交或补丁，本地集成按现有会话授权及根AGENTS执行；推送/开PR/发布仍按用户授权。

## 3. 现有真实入口与契约

`app.py` 实际使用 `PluginEnabledCompanionController as CompanionController`。手机宿主必须接到这条已包含 Emotional Memory V2、persona、插件与失效传播的路径，不能仅创建基础 `controller.py` 的实例就宣称跨端记忆已接通。

网络线程提交类型化命令，由宿主在适当线程串行处理；Qt 对象和同一角色存档不由多个网络回调并发写入。LLM 调用、语音与取消不能堵塞 UI 的响应与关停。具体调度复用当前模式，只有实际需要时拆分。

首版契约至少覆盖：

- 配对/撤销、能力查询、已认证设备映射；客户端自报 owner 不能决定服务端 namespace。
- 当前角色、会话消息、取消回复、表达/记忆版本。
- 查看/确认/纠正/遗忘记忆及来源；继续使用现有 V2 用例。
- 建议、用户批准、任务/外部编号、状态、最后核对时间、事件游标、结果引用、取消回执。
- 主动分享及观察授权/有效期/撤回；没有完成派生撤销前不启用被动观察。
- 结构化错误、重复请求语义、断线恢复、电脑离线与能力不可用。

以上是待实现责任，不是已有 HTTP 端点。Codex先交付能被运行的最小契约与服务路径，Claude据此接真实客户端；前端 fixture 可用于布局和状态预览，必须明显标注，不能作为手机/Relay已连接的证据。

## 4. 第一条联合开发闭环

**Android 手机与桌面配对 → 使用同一角色聊天 → 手机明确记住/纠正一个事实并在桌面召回 → 用户采纳一项任务 → 接到真实权威执行者 → 手机查看带来源的阶段报告 → 取消/断线后状态仍可核对。**

第一步就保留 iOS/华为手机所需的公共语义，不同时铺开三个没有可运行连接的客户端。默认先 Android，因为用户当前设备是 HyperOS 4；这不取消 iOS 和华为手机目标。

| 阶段 | Claude | Codex | 可交付结果 |
|---|---|---|---|
| 共同基线 | 审阅需求/现有UI | 导入已有累计改动、核对真实入口 | 一致的代码基线与少量明确文件分工 |
| 聊天与记忆 | 配对/角色/聊天/记忆页面及Android客户端 | 宿主facade、认证、会话和V2服务接入 | 真机聊天和跨端事实纠正；关闭工作仍可用 |
| 任务闭环 | 建议批准、进度卡片、取消/未知状态 | 对接真实Relay契约、持久runner、事件恢复 | 实际外部任务与阶段证据；接口缺失清楚标出 |
| 观察 | 主动分享、范围/授权/停止、原生collector | 来源/epoch、派生历史/TTS/cache撤回 | 权限关闭后迟到结果不能再次展示/召回 |
| 其他手机 | SwiftUI iOS、ArkUI华为手机 | 共用协议和能力差异 | 每平台分别构建/真机验收 |

Relay接口若当前不可调用，完成 E-Moti 侧实际可验证部分与明确的对接规格，记录阻塞；不修改 Relay 仓库、不把模拟执行者报告为联通成功。任务监听与常开宿主不依赖手机后台长连接。

## 5. 反馈与集成

接口变更由主写者提交一个可运行的小切片并说明行为变化，另一方接入/评审；不要只互传庞大设计稿。发生歧义先查实际代码和官方文档，再自行选择可逆实现。真正缺少授权、凭据或设备时报告具体缺项，其余工作继续。

每次交付写明 commit、用户行为变化、实际命令/结果、模拟部分及未验证项。复用未失效证据；文档变化只做轻量检查，运行时变化按根 `AGENTS.md` 做相关测试和必要回归。达到当前切片验收标准后停止无关扩展。
