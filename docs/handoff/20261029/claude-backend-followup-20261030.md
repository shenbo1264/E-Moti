## 行为和接入

- 事实提取继续由 Codex 维护。Claude 现有 `DesktopDialogueService` 调用无需新增接口。明确的普通聊天计划走同一 V2 存储，支持 auto/review/off；候选有效期可跨重启保留。计划带原话、来源、原时间表述和 `plan_status=planned`，摘要明确标注“未确认完成”，不写永久画像。
- “下个月”“七月”等仅保留原文字面，不推算年份或已发生日期。30 日有效期是既有逻辑时钟上的记忆新鲜度，不是计划的日历截止日。没有新增数据库或批量存档迁移。
- 自然遗忘支持“把我狗的事忘了吧”“某某考试那件事别记了”等话题前置表达；匹配实际可信用户事实与候选，复用来源撤回、epoch、章节/画像/历史/缓存失效。引用、虚构、假设和“不要忘记”不会触发删除。目标不明返回 clarify，模型返回空提议也不能宣称已遗忘。
- 计划的语义纠正保留原时间、计划状态和有效期；旧明确记忆同样适用。review 沿现有原子确认替代，时间变化不明确时澄清。不会把未来迁居纠正成“用户住在某地”。
- 纠正原话可能同时提及旧值与新值。本轮聊天仍可供界面阅读，但不再参与后续 prompt；后续使用更新后的有效事实。真实模型复测发现此缺口后，已增加跨重启回归。
- 抽取期间发生到期、模式或来源变化时，继续拒绝迟到结果。Claude 的一般模型提议校验失败仍可恢复聊天，但真实过期上下文不能被转换成普通澄清并继续使用。

Claude 可继续在回忆册查看来源、候选与计划文字，验收普通聊天和人格陪伴体验；不要再实现另一套事实提取。后端仍只消费模型提议，不允许模型直接写存档。

## 验证与模型证据

原四个失败场景 `fact_move`、`fact_midchat`、`forget_pet`、`forget_exam` 的本地存储行为已通过。OpenAI 环境凭据返回 HTTP 401，本轮这两个模型的有效输出为零，模型状态为 `not_run`；字面存储通过不等于模型通过。`companion_live_eval.py` 已增加独立的 `model_status` 字段。

随后只读使用桌面应用已启用的 DeepSeek 配置，未修改配置或记录凭据。`deepseek-v4-pro` 的真实茶饮链路 14/14 检查通过，包含实际 ONNX 召回、重启、纠正/遗忘后 prompt 与缓存清理，以及三次真实生成。原 38 条开发契约保持 38/38。

新增三条合成轨迹走实际桌面服务和持久存储：普通计划跨重启召回、旧计划纠正后跨重启召回、话题遗忘后跨重启询问。初轮 6 次真实调用、18,834 实际 token，最长 25.662 秒。保留初轮结果，不将字面命中视作整体回答正确：

1. 计划地点召回正确，但角色将自己此前问过的“桌角会不会换个朝向”归到用户头上。prompt 已标注 user/assistant；这是仍未解决的回答归因问题。
2. 纠正后的回答复述旧地点；检查发现纠正原话进入了新 epoch 的聊天记录。后端已修复历史进入 prompt 的路径，并另行真实复测，原 bad case 保留。
3. 狗名字遗忘后，存储、后续 prompt 和回答均未出现原名字。遗忘动作由宿主完成；随后的询问才调用真实模型。

人格表现仍需 Claude 验收，不能据本批字面命中或 persona 配置不变判为全面通过。真实生成工具沿用 60 秒超时，桌面既有设置为 30 秒；报告保留实际延迟。
