# E-Moti 课程提交技术附件

本附件承接主文中不适合展开的工程验证、AI 能力边界、素材来源和后续限制。主文面向五分钟作品介绍；附件用于导师或助教进一步核对实现情况。

## 1. 交付包与运行边界

推荐提交物为 `dist/E-Moti-course-submission.zip`。解压后运行 `E-Moti.exe`，可直接体验控制面板、桌宠模式、基础互动、商店背包、三角色切换和本地养成反馈。

预配置环境中可体验 DeepSeek 对话、MiMo 屏幕理解、主动话题和语音能力。它们属于增强体验，不改变基础游戏闭环；未配置时，桌宠仍可用本地规则运行。

课程版不提供后台持续监听、唤醒词、鼠标键盘控制、剪贴板控制、开机自启或系统级自动化。屏幕理解和搜索只在授权后作为只读上下文进入角色表达层。

## 2. AI 运行时边界

AI 被限定在“角色表现层”：

- 可以生成角色台词。
- 可以建议表情、动作和互动意图。
- 可以读取授权后的屏幕摘要、搜索结果和近期对话。
- 不允许直接修改状态、金币、背包、关系、目标、记忆或存档。

ASR 只产生玩家输入文本，进入正常对话流程。TTS 只消费已经通过事件校验的角色台词。屏幕理解和联网搜索只作为只读表达上下文，不控制电脑。

## 3. AI 工具与使用方式

| 阶段 | 工具 / 模型 | 实际用途 |
| --- | --- | --- |
| 产品设计 | ChatGPT、Codex | 梳理设计假设、竞品观察、角色包路线和交付优先级 |
| 代码开发 | Codex | 修改代码、补测试、排查打包和运行问题 |
| 文档复审 | ChatGPT、GPT-5.5 Pro 反馈、Codex | 复审交付文档结构，按产品表达重构 Markdown / PDF |
| 角色对话 | DeepSeek | 生成角色回复、表情建议、动作建议和互动意图 |
| 屏幕理解 | MiMo 视觉模型 | 授权后读取屏幕截图摘要，作为主动话题上下文 |
| 美术生产 | ChatGPT 图像生成、Codex 资产整理工作流，参考 hatch-pet 像素宠序列帧工作流 | 生成角色候选、像素宠物序列帧和角色展示资产 |
| 语音能力 | Qwen3TTS、GPT-SoVITS、SenseVoice ASR 等方案 | 验证角色音色方向、TTS 输出和 ASR 输入链路 |

“借助 AI 辅助梳理”指的是设计假设、竞品观察和方案取舍，不等同于已经完成正式问卷或访谈。所有进入提交文档的结论都按真实仓库、截图、测试输出或实机验证核对。

## 4. 素材与权利说明

星汐是本项目原创主角色，用于展示可公开分发的主体验方向。伊卡洛斯和奶龙用于非商业课程演示中的角色包兼容性、风格差异和玩家自定义方向验证，其角色与原始知识产权归各自权利方所有。

当前课程包中三套角色均可见、可切换；这不代表对第三方角色 IP 的商业授权声明。后续若公开发行或商业化，应将第三方角色替换为原创角色包，或取得明确授权。

美术资产生产采用“AI 候选 + 人工筛选 + 运行时 QA”的流程。像素桌宠形象强调小尺寸清晰度、边缘干净和帧间一致性；角色卡视觉用于角色库展示，不替代桌宠序列帧。

## 5. 角色包结构

每个角色包至少包含：

```text
character.json
dialogue_style.json
motion_manifest.json
spritesheet.png
preview/
item_icons/
shop_items.json
```

运行时切换角色时，会同步切换外观、对话风格、商店主题、角色音色配置和独立记忆路径。角色切换不是单纯替换图片，而是替换一整套角色体验配置。

## 6. 美术路线取舍

前期探索过更精细的 GalGame 立绘、AI 视频转序列帧、LivePortrait 和 Live2D 路线。它们能提升表现上限，但对课程提交版有几个现实问题：

- 帧间一致性难以稳定保证。
- 透明边缘和缩放后噪点更容易暴露。
- Live2D 需要模型拆分、绑定和动作制作，不适合临近交付时强行切换。
- 第三方角色训练、音色和素材授权会增加不可控风险。

因此课程提交版采用像素宠物序列帧路线。它更适合桌面小窗口，便于做眨眼、呼吸、轻触、移动等短动作，也更容易形成可复用角色包工作流。

## 8. 已知限制

- 语音能力已经有角色音色配置和服务联调，但后续仍需要进一步压缩模型体积、优化冷启动和统一一键启动体验。
- 主动陪伴已经具备屏幕摘要、搜索线索和话题准备链路，但仍需要更细的打扰频率、时机和拒绝后的冷却策略。
- 星汐的原创视觉仍可继续统一角色卡和像素桌宠的识别点，例如发色、星星配饰和服装细节。
- Live2D 与 AI 视频路线保留为研究方向，不作为当前课程提交版的主路线。

## 9. 推荐演示顺序

1. 打开 `E-Moti.exe`。
2. 展示星汐总览和桌宠模式。
3. 轻触星汐，观察台词和状态变化。
4. 购买热牛奶并投喂，展示金币、背包和状态变化。
5. 切换伊卡洛斯和奶龙，说明多角色包能力。
6. 在预配置环境中演示一次 AI 对话。
7. 如环境允许，开启屏幕理解并展示主动话题。
