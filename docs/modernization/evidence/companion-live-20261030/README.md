## Bad case

1. `fact_move`、`fact_midchat`：两个模型都没记下“下个月搬去杭州”“七月考雅思”，回复却自然接住了。规则把计划类和含“今天”的句子全部排除。
2. `forget_pet`：“把我猫的事忘了吧”模型提议未通过校验，**这句聊天直接报错**。已修为转成澄清提示（`desktop_dialogue_service.py`），事实仍未遗忘。
3. `forget_exam`：“雅思那件事别记了”没有触发抽取，角色回答“不再提了”，**事实仍在库里，回答与实际不符**。这是最严重的一条。
4. 人格初步观察（未盲评，不算得分）：terra 多次写出第三人称舞台描述“星汐从桌角探出头”，`persona_work` 语气接近通用助手；luna 更贴近短句吐槽。两者都尊重了拒绝，也都没有无条件赞同。
