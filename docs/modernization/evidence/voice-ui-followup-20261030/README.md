## 实际修改

- 13 个现有页面统一文字、输入、菜单、焦点和禁用状态。修复总览说明挤出状态卡、底部操作不可达、导航随内容滚走及下拉箭头消失。保留角色素材、存档、插件与现有能力。

## 问题与证据演变

1. 游戏吐槽曾回答“不是对面手感太好，就是手一滑按错键了”，虚构败因。最终为“那局倒像专门跟你作对似的”，改为明确比喻，没有补写操作过程。
2. 宠物改名中间轮出现旧事实未正确替换，以及已保存新名字却未进入最终 prompt 的不同失败。最终保存“狗叫松子”，重开回答“松子”，旧名字未进入最终 prompt。`missing/leaked` 仅检查样本定义的字面项，不能单独代表回答正确；必须结合请求和回答。
3. 用户纠正搬家地点时，最后一轮仍出现“那是我记岔了”，近期历史没有其先答错的证据；这是未解决的归因偏差。最终地点回答为泉州，存储与召回正确。
4. 中间版袜子玩笑真实模型原文含 `��`，原样保留；客户端使用严格 UTF-8 解码，该字符来自返回内容。最后一轮未再出现，不能据此宣称永久解决。
5. 真实桌宠聊天“我喜欢喝桂花乌龙茶”触发自动记忆和回忆提示，但回答含“我只在边上闻过”，为无依据亲历。对应 `final-desktop-chat.*` 是界面验证时的中间表达版本；后续规则补充了感官经历约束，未用后来的答案替换这张证据。
6. 最终仍有“就别惦记着这事了”“连着熬只会让第二天更糟”等偏强或未经请求的安排；人格质量尚未达到全样本通过。不能把格式通过、配置稳定或测试数量当作人格达标。
