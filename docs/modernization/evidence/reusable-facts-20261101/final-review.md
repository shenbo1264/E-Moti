# 独立事实能力最终复核

最终七例结论由 `after.json` 的前六例及补修后的 `occupation-final.json` 共同提供。七例均通过各自的实际保存、更正、空聊天历史重启召回、遗忘及无关事实保留检查。原 `after.json` 的职业样本失败，完整保留于该文件和 `after-review.md`；本结论不把原七例运行改写成全通过，也不代表七例在最终版本上重新整批运行。

## 职业例补修结果

`occupation-final.json` 的更正返回 `saved`，存档为“用户的舅舅的职业是调音师”，保留“我的舅舅叫裴岑”和“我是摄影师”。旧职业园艺师已从有效事实移除，没有将舅舅职业写成用户职业。

逐次检查全部实际 `calls.messages.content`：更正轮第一次是事实抽取请求，含旧园艺师与用户提出的新调音师；之后两次对话相关请求已不含旧职业，只含新职业。空历史重启的两次真实请求均含调音师、不含园艺师，回答“裴岑是调音师。”。这与抽取器为确定更正目标而读取旧事实属于不同阶段。

按字段遗忘返回 `forgotten`，只删除舅舅职业。舅舅姓名裴岑和用户摄影师事实保留。忘后立即、再次清空历史重启的四次实际请求均无旧新职业，两次回答都是“这个我还不知道。”，没有追问重新登记。所有重启轮聊天历史为空，无 fallback。

这些指标针对七个合成输入和指定的两个忘后查询。它们验证具体链路的持久保存及 prompt 交付，不是开放域检索准确率或全面人格质量评分。

## 原游泳、教师案例回归

`schedule-regression.json` 保存“用户每周日去游泳”，用户姓名许安保持。空历史重启实际请求含周日、不含周六，回答“周日呀，我记得这个。”。遗忘后只剩用户姓名，两次实际请求均无周六或周日，回答分别为“这个我还真不知道呢”和“这个我不知道欸”，没有追问安排。统计必须匹配“周六/周日”等完整时间词；仅搜“日”会误中系统指令中的“日期”等词。

教师回归结果沿用 `after-review.md`：保存江屿、空历史重启答江屿、遗忘后两次无旧新姓名，用户许安保持。仍保留“这名字听着就像会弹吉他的人”这一无依据联想 bad case，不能宣布人格风格全面达标。
