## 实际增量

1. 普通聊天可以提取有原文来源的日常事件与约定，区分计划、已完成、取消、未发生；保存原子引用、活动、参与者和来源位置。近期候选按当前内容选择，避免只给抽取器最旧的一批记录。计划不自动升级为共同经历，执行器完成也不等于用户验收。
2. 对象属性按原话主体与字段绑定；偏好增加人物和活动范围。用户与亲友的相似偏好分别保存，更正仅选择同主体、同范围目标。每周活动改期继承已有频率，自然语言遗忘支持关系字段、活动时间和范围偏好。仍使用原有长期事实权威存储，没有第二套事实数据库。
3. 原文支持位置保存为有界 `source_support_spans`。撤销一项事实时同步撤销同一来源中覆盖该片段的宽引用与派生内容，保留不重叠的有效事实，避免借另一张卡的整句引用泄漏刚忘掉的信息。旧卡缺少精确位置时采用已有保守来源失效规则，不猜造历史位置。
4. 最终证据检查继承档案明确的 Unix 时间；旧逻辑时钟仍为 logical。身份依据中的计划用语不再覆盖历史查询时间。共同经历接收宿主角色包的真实显示名，同时要求受信参与者与原文证明；同名亲友、较长姓名前缀、转述、计划和未来事件仍须被拒绝。
5. 官方 DeepSeek 的事实提取与表达审阅使用 `reasoning_effort=none`，解决推理耗尽输出预算而正文为空的问题；表达草稿流程与角色配置保持原样。证据判断首次仍为 low，仅空正文或 JSON 语法失败允许一次 none 格式恢复，候选和问题不变；语义不充分、绑定错误、权限失败不会通过重试挑选答案。恢复前后核查来源版本及角色，迟到结果不能复用。
6. 外部公开 benchmark 增加原生聊天回放、隔离答题、逐请求证据与独立评分工具。新发现的余额耗尽没有及时停机问题已修正：HTTP 402 保存当前位置后停止，评分器也停止提交后续请求。

DeepSeek 参数选择依据[官方接口说明](https://api-docs.deepseek.com/api/create-chat-completion/)与[思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。格式恢复不改变模型权限或记忆写入权威。
