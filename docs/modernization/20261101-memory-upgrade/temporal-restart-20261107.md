新增 `tools/eval_memory_process_restart.py`。一个父进程顺序启动三个全新子进程，分别打开同一隔离测试档案；各阶段清空聊天历史。所有子进程共用持久预算，在发出请求前预留费用，不会因进程重启重置额度。未完成的在途请求、失败和异常立即停止，不能自动续跑。
