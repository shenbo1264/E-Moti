## 真实验证的解释

第六密封集在开发者未看题目前冻结于 `bd9fabd`：6个故事、48个问题、每档案300条，同一上下文预算、真实BGE和 `deepseek-flash`。其中30道有据、11道无答案。结果如下：

| 路线 | 严格证据交付 /30 | 无答案误注入 /11 | 有据回答正确 /30 | 正确且格式合法 /30 | 人格通过 /48 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无长期记忆 | 0 | 0 | 0 | 0 | 29 |
| 旧词法 | 28 | 7 | 28 | 28 | 44 |
| 旧 BGE + RRF | 28 | 9 | 29 | 29 | 43 |
| 新路线＋可选判据 | 30 | 0 | 30 | 29 | 47 |
| 新路线＋分层 | 29 | 0 | 29 | 28 | 45 |

这是新独立数据上的正向结果，不能据此宣布所有泛化问题解决。新两路在无需检索问题上仍有6/6准备开销，分层有1条误拒，另有2条内容正确但格式非法的实际输出。未放宽解析器，也没有自动修补字段冒充首轮通过。两条错误分别是把 `speech` 键写成表情标签，以及JSON字段间使用错误冒号。官方 [Chat JSON模式](https://api-docs.deepseek.com/guides/json_mode/)已按要求启用，实测仍以本地契约验证为准。

包含通识、陪伴、无答案等全部48题时，原文正确通过为旧BGE47、新路线46、分层45；正确且格式可交付为47、45、44。因此当前增量改善了有据检索与无关注入，但整体可交付回答仍未全面超过旧BGE，保持开发候选状态。
