# 去掉普通分享后的多余人格评价

本批修复“倒挺有主见”这类与当前话题无关的对人评价，生产提交 `700e272`，真实评测提交 `18651ff`。更新同一草稿 PR #7，不合并。用户要求每批不超过0.50元；本批已经结束，没有继续调用模型。

## 改动

原有规则约束反对时的能力评价、无依据事实和多余建议，但没有清楚区分：角色对某件事物的具体感受，以及从用户一次选择推断其性格、品味或能力。

增加一条生成与审阅共同使用的规则：普通偏好和一次选择不自动成为对人的评分、夸赞或人格定论；保留角色对事物本身的喜恶、联想、拟人和轻巧玩笑。用户主动求评价或求夸奖时，仍可针对已说出的具体选择、努力或成果回应。审阅记录增加 `unsolicited_evaluation` 类别，不增加模型调用轮次。

没有按“有主见”做字符串删除，没有修改角色 persona 或套用客服回执；也不删除作者给角色自己的性格设定。模型输出仍走原有草稿、一次审阅、最终事件校验与取消流程。
