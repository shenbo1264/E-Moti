## 已实现

- 时间解析结果直接参与查询路由，中文日期不再被第二套数字正则判成闲聊。个人“完成/进展”不再自动假定有外部执行者；明确外部任务仍要求实际权威状态。
- 证据模型通过 `question_ref` 引用宿主原文编号，避免自由改写问题造成引用失败。多个时间、scope、权威和共同参与约束不能用整问编号覆盖；旧协议保留兼容。
- 明确否定采用逐条原文claim用途，允许计划卡中独立的否定现状，保留条件、疑问、未知和纯预约拒绝。它尚未解决所有模型标签组合，失败保留。
- 多轮指代可有界补入身份来源，`antecedent` 引用用户历史中的提及；历史本身不证明身份，最终仍核查真实别名来源、同名冲突、指纹与撤回。
- 增加公开聊天 benchmark 的单题原生回放工具。用户消息进入当前记忆处理/抽取，保留原助手回复；关闭后复制测试档案、以新controller重新打开、清空短期历史再答题。没有依据标准答案补写记忆。
