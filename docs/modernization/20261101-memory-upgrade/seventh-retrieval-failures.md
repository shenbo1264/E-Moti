## 判读限制

- `v7_games_q1` 的“保管/携带”歧义单独列出，原标签不变，不能事后删题提高分数。
- `v7_bread_q3` 的日期错误来自保存的真实模型推理；不能反过来把该日期当作宿主真实时间或用户事实。
- 一张卡片通过另一个子问进入 Prompt，可能让生成模型回答更多内容，但不意味着子问状态已经正确，也不能直接证明最终角色回答正确。
- 第七首次数据继续完整保存；接下来修复这些通用问题后的第七重放属于已见回归，新的泛化判断需另用密封样本。
