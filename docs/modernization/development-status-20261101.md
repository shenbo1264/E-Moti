# 桌面开发状态与本次 PR

更新：2026-11-01。PR 基于 `main` 的 `79c8377`（Claude 产品/UI PR #5 已合并），汇集 `codex/desktop-acceptance` 的四个本地提交及后续修复。当前主线仍是 Windows Python/PySide6 桌面记忆、人格与陪伴；手机和长程工作保留为后续方向。

## 本次提交的行为

| 部分 | 改动与当前结果 |
| --- | --- |
| 桌面界面 | 13 个既有页面统一标题、导航、间距和控件表现；导航与正文滚动分离，修复主窗口底部操作不可达、下拉箭头缺失和桌宠输入/记忆提示布局。已有真实 Windows 鼠标点击记录。 |
| 普通聊天与主动陪伴 | 连续“也/还”偏好自述沿用同句主语；待确认、纠正和遗忘反馈以角色口吻呈现。明确“先别打扰”沿用持久冷却，不调用模型，也不写成长期事实。 |
| 记忆更正 | 宠物更正保留种类；教师姓名绑定已有同一人物关系，不能写成用户姓名；每周安排按活动保存和改期，旧明确记忆参与只读匹配。auto/review/off 沿用原设置。 |
| 来源失效与召回 | 复用现有 V2、来源指纹、epoch、supersedes 和回忆册。长问题按句补充词法相关度；纠正/遗忘后旧内容不重入 prompt。没有第二套事实库或存档格式迁移。 |
| 角色表达 | JSON 单对象契约与客户端一致；角色草稿后最多一次基于证据的台词修订，保留演出字段。桌面与宿主传递取消信号，两次请求共享总 deadline；草稿不进入聊天历史或 TTS。 |
| 表达分寸 | 检查无依据自责、突兀呼名、额外建议、感谢代写补日期/完成范围、无依据新旧时间关系。无答案的个人回忆问题只简短表达未知，不追问索回；明确要求规划仍可澄清，普通玩笑保留。 |

没有改默认角色、资产分发权、插件边界、Relay 或其他项目。手机页面仅随桌面公共样式调整，未扩展手机配对、推送或观察能力。宿主沿用现有单写入权威与线程边界。

## 真实验证

- 实际使用应用 `deepseek-flash`（用户指定 V4.1 Flash）；测试数据为独立合成存档。原始请求、草稿、回答、token、延迟和失败全部保留。
- 教师林澈→江屿、游泳周六→周日：更正实际持久保存，清空聊天历史并重启仍能召回新值；遗忘后即时及重启请求均无新旧值。用户姓名独立保留。
- 独立普通自述的跑步周三→周五也通过上述链路。遗忘后的四条最终回答都只短答不知道，不邀请重告重记。明确规划和角色玩笑控制通过。
- 最新最终提示相关测试 29 passed。最近一次全量为 **1693 passed / 2 failed / 5 skipped**，两项是界面响应 125ms 超过 100ms 阈值、portrait 起始帧顺序不同；原断言单独复查 2 passed。不能报告全套全绿。全量在第一版遗忘规则时启动，最后短答文案以相关测试和真实请求补验。
- 此前每周安排实现最终全量为 1695 passed / 5 skipped；38 条开发记忆契约通过。后续只改表达规则，未把这些契约当作模型行为验收。

## 成本与尚未解决的事项

正常聊天最多多一次修订请求；早期同一16场景对照由71,946增至122,318实际tokens（约70%），延迟也增加，不能视为无成本优化。最后教师/游泳/控制组分别为9/8/8次调用，21,223/20,186/16,483 tokens；每轮实际耗时在证据中。

模型表现只在记录中的有限样本验证，AI 评审不等同人工长期体验。保留随机失败、基线已通过及未带来新增改善的对照；不得据此宣称人格升级全面完成。两项仅在全量出现的计时/帧序失败仍需关注，未放宽测试阈值。此次没有重新构建安装包，也没有完成手机真机、Relay 长程或跨小时任务验收。
